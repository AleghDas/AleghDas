# Publish your GitHub public profile

This kit was prepared for GitHub account **AleghDas**.

## 1. Create the special public repository

1. Log into https://github.com/AleghDas
2. Open https://github.com/new
3. Set **Repository name** to `AleghDas` (the same as your username, including capitalization).
4. Set **Public** visibility.
5. Optionally select **Add a README file**, then click **Create repository**.

## 2. Upload the profile content

Upload the `README.md` file and the entire `assets` folder from this package
into the repository's root. On GitHub, open the repo, choose **Add file → Upload files**,
drag in `README.md` and `assets/header.svg`, then commit the changes.

If GitHub already generated a `README.md`, edit/replace its contents with
the included `README.md` instead of uploading a duplicate.

Your public profile will then appear at:
https://github.com/AleghDas

## 3. Update the account profile

Open https://github.com/settings/profile and consider these fields:

- **Name:** Alegh
- **Bio:** Software Developer • Designer • AI Product Builder | Python, FastAPI, React, AWS
- **Website, social links, location:** add only what you're comfortable making public.
- **Profile photo:** use your preferred professional photo.

## Notes

- GitHub uses `README.md` at the root of a public repository with your username
  to display a custom profile.
- The `assets/header.svg` file is referenced by the README and must also be uploaded.
- You can edit the README any time as your projects evolve.
- No private employer details, unpublished source code, or personal email address
  were included in this package.
